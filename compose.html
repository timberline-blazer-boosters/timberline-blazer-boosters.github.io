Compose a post

Officers: pick one photo, a carousel, or an MP4 reel. This page converts photos to Instagram JPEGs and sends tags with the package. Unless you check website-only, Make can publish that package to Instagram and Facebook. Tokens stay in Make.

Media type
Image (required)

Drop a photo here or click to choose. Drag to position it in the 4:5 frame.

Each photo is converted to a 1080×1080 JPEG (Instagram carousel default). First photo sets the crop.

Send an MP4 reel as-is. The browser does not convert video. Instagram does not use alt text on Reels.

What Make receives

One photo: 1080×1350 JPEG, caption, alt text, tags. Carousel: 2–10 JPEGs at 1080×1080, caption, tags, media_type=CAROUSEL. Reel: the MP4 you chose, caption, tags, media_type=REELS (no alt text). Check Website only to skip Instagram and Facebook.

If a post with that title already exists for today, change the title and try again. Do not overwrite posts.
